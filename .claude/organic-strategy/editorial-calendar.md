## Princípios do Calendário

1. Frequência sustentável antes de frequência ideal — 5x/semana é melhor que 7x/semana insustentável
2. Cada semana tem pelo menos um conteúdo de cada nível de funil (ToFu / MoFu / BoFu)
3. Os pilares rodam em sequência — nenhum pilar domina 2 semanas seguidas

## Notas de Produção

### Para cada post de carrossel
- Slide 1 (capa): gancho forte — pergunta, dado ou afirmação provocativa
- Slides 2–N: desenvolvimento com visualização clara, não muita cópia por slide
- Último slide: sempre CTA + @ars.compliance (ou o handle oficial)
- Sempre salvar versão para story de republica

### Para cada Reel
- Primeiros 3 segundos: gancho que prende — frase falada ou texto sobreposto
- Narração: tom direto, sem jargão, linguagem de quem explica para um colega
- Duração ideal: 20–45 segundos
- Legenda sempre ativada (acessibilidade + quem assiste sem som)

### Hashtags padrão (rotação, não usar todas em todo post)
**Bloco A (compliance/ISO):** #compliance #ISO27001 #LGPD #auditoria #gestaoderisco #segurancadainformacao #DPO #ISO9001  
**Bloco B (negócios):** #empreendedorismo #gestao #tecnologia #startups #PME #governanca  
**Bloco C (nicho exato):** #certificacaoiso #auditreadiness #compliancedigital #GRC #maturidadedeprocessos

**Regra:** usar 5–8 hashtags por post. Misturar 2–3 do Bloco A + 1–2 do Bloco B + 1–2 do Bloco C.
