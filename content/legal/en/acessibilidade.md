## 1. Commitment

We want the platform (`app.auditcockpits.com`) and the website (`auditcockpits.com`) to be usable by
everyone, including people using assistive technologies. Our design target is **WCAG 2.1 level AA**.

## 2. Current status

**Partially conformant (self-assessment, no independent audit).** What is already in place:

- a "skip to content" link as the first focusable element;
- status is never shown by colour or icon alone: text always accompanies it;
- interface components built on accessible libraries (Radix UI), with ARIA attributes;
- the interface is available in Portuguese, English and Spanish.

Known limitations:

- there is no independent accessibility audit and no automated accessibility testing;
- charts and visual indicators may not have a complete text alternative on every screen;
- colour contrast of some combinations and keyboard-only navigation have not been checked on every screen.

## 3. Plan

We will add automated accessibility tests to the development process and run a WCAG 2.1 AA audit before the first customer in the European Union.

## 4. Contact

Found a barrier? Write to **suporte@auditcockpits.com**. We will reply within 5 business days and offer
an alternative while we fix it.
